🌤️ Projeto Clima
Uma aplicação web de consulta meteorológica desenvolvida com HTML, CSS e JavaScript.

O projeto permite pesquisar diferentes cidades e visualizar informações atualizadas sobre o clima de cada localidade, através de uma interface simples, moderna e responsiva.

🚀 Funcionalidades
🔎 Pesquisa de qualquer cidade

🌡️ Exibição da temperatura atual

☁️ Exibição das condições climáticas

💧 Informações sobre umidade

💨 Informações sobre o vento

📱 Interface responsiva

⚡ Atualização das informações conforme a cidade pesquisada

🛠️ Tecnologias utilizadas
HTML5 — Estrutura da aplicação

CSS3 — Estilização e responsividade

JavaScript — Lógica da aplicação e consumo da API

API de clima — Obtenção dos dados meteorológicos

📸 Demonstração
Aplicação desenvolvida para pesquisar cidades e consultar suas condições climáticas em tempo real.

🌎 Como funciona
O usuário informa o nome de uma cidade no campo de pesquisa. O JavaScript realiza uma requisição à API meteorológica e utiliza os dados recebidos para atualizar a interface com as informações climáticas da cidade pesquisada.

O projeto também trabalha com manipulação do DOM, eventos e requisições assíncronas utilizando JavaScript.

📱 Responsividade
A aplicação foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência adequada em:

💻 Computadores

📱 Celulares

📲 Tablets

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web, principalmente em:

Estruturação de páginas com HTML

Responsividade

JavaScript
